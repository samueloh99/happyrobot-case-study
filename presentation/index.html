03 Design Guarantees

Three things that can't break.

01

The rate ceiling never leaks.

The negotiation service returns only action and counter offer — never the ceiling itself. When a carrier asks "what's your max?", the agent has nothing to reveal.

02

The OTP can't be talked around.

The verification code is generated, stored, and checked server-side. "My dispatcher waived it" is a hard no — the server just says yes or no.

03

Booking never retries.

If the TMS times out, we can't know if the booking committed. Retrying could double-book. So we fail loudly, promise a senior-rep callback, and log honestly.
